# 暗区战地商人 · 听声识物

适用于 Windows PC 版《暗区突围：无限》S7 战地商人的神秘货物。工具读取系统正在播放的声音，尝试识别拖动货物时的拾起或放下音效，并列出该音效组可能对应的物品。

## 使用方法

1. 双击 `商人听金.exe`。
2. 在“游戏播放设备”中选择游戏声音实际输出的设备，然后点击“开始监听”。如果使用 SteelSeries Sonar 等虚拟设备，请选择游戏指定的那一路（通常是 Gaming）。游戏里也可以直接按 `Alt+4` 开始/停止监听、`Alt+5` 显示/隐藏窗口。
3. 在游戏里拖动一件神秘货物并放下，程序会自动尝试识别（连续两次同一候选才更新，识别到后会安静 3 秒，避免刷屏）。
4. 选择货物占格，缩小候选物品范围。价格显示的是参考数据中的联系人价格，可能随版本变化；超过 100 万的价格用深红色标出。
5. 识别结果只显示最相似的那一组，物品按左右两列排布，每项依次是物品名称、占格尺寸、联系人价格和类别；价值高于 100 万的物品价格显示为深红色。若该组的某个规格里出现过百万的物品，占格下拉框右边会出现红色描边提示（如「买2×3！」）。所有结果文字带黑色描边，浮在游戏画面上也能看清。
6. 勾选“窗口置顶”可将工具固定显示在其他普通窗口前面；默认已开启。“背景透明”默认开启：整个窗口底色会被抠掉，只留文字和控件浮在游戏画面上，包括候选列表的背景；透明区域的鼠标点击会穿透到游戏（移动窗口请拖标题栏）；取消勾选即可恢复原来的深色底。旁边的“面板不透明度”滑块可让剩下的文字和控件一起变半透明（30%–100%）。程序不挂任何鼠标/键盘钩子，只注册了 `Alt+4`、`Alt+5` 两个全局热键。若游戏使用独占全屏模式，请切换到无边框窗口模式，以便同时看到游戏和工具。

占格筛选会把旋转后的 1×2/2×1、2×3/3×2 视为同一种尺寸。识别结果只显示最相似的一组，物品按左右两列排布，一屏基本能看全，不需要滚动；窗口可自由缩放，字号会跟着窗口大小自动调整。

如果没有结果，先确认选对播放设备，再连续拖动同一件货物两三次。背景音乐很响或有其他游戏声响时，可以短暂降低音乐音量复核。一次只拖动一件更容易识别。

自动模式先用音效前段给出“快速匹配”；手动按钮会用更完整的音效复核。快速结果建议结合货物占格判断。
对于很轻的音效，程序可能显示“低音量匹配，建议复核”；这表示同一候选连续出现，但相似度不足以直接确定。
新版会同时比较完整频段和偏高频的短音效特征，并在匹配分很低时检查音效在混音中的峰值强度，以减轻背景音乐遮盖。连续两次出现同一候选才会自动更新结果，拾起和放下若属于同一声音组会保持显示。

## 结果如何理解

- “匹配分”是录到的音频与参考音效的匹配程度，范围为 0–100；它不是物品的掉落概率。背景音乐、系统音效处理和其他声响仍可能影响结果。
- “音效峰值强度”用于背景音乐下的补充判别，没有百分比意义，也不是掉落概率。看到“建议复核”时，请结合占格与再次拖动确认。
- 不同物品可能共用同一音效。程序识别到的是**声音组**，不能保证确定唯一物品。
- 同一声音组内的物品共用同一段参考音效（`reference/` 目录中的拾起、放下两段 ogg）。
- 参考表中有 38 组音效、189 件有声音分组的物品。游戏更新、音效被其他声音盖住或播放设备处理了音效时，结果可能不准确。
- 宝石项链在当前表中，属于 33 号声音组。非线性节点探测器不在当前战地商人参考表中，因此工具暂时无法识别它，也不会猜测其声音组。
- 候选物品显示简体中文名称、占格尺寸、联系人价格与类别，不再显示物品图片。中文名称由繁体中文游戏名称转换而来，少数名称可能与简体版游戏用词不同。
- 程序只监听本机播放声音，不读取游戏内存、不修改游戏文件，也不向服务器上传录音。

## 逐组测试

附带《逐组召回测试报告.md》和《逐组召回测试.csv》，列出 38 组拾起、放下音效在四种模拟背景下的识别结果。共测 304 次，安静 76/76、低频音乐 76/76、高频音乐 74/76、宽带杂音 76/76。宝石项链（33 组）在四种场景的拾起和放下均识别成功；高频音乐下仍有 11 组拾起、15 组放下两段未识别。测试用的是参考音效和模拟混音，不代表实际游戏录音的召回率。

## 数据来源

音效和物品对应关系取自社区维护的 [ABI Builder 战地商人页面](https://abibuilder.com/merchant)，中文名称取自 [abi-assets 游戏本地化数据](https://github.com/hexaov91/abi-assets/tree/main/localization/game)并转换为简体。参考表的游戏数据版本为 `1.0.0.151.4`。这些是社区资料，可能存在误差或过期；请以游戏内实际结果为准。本工具与游戏官方及上述社区项目无关联。
